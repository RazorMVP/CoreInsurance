# NubSure Documentation

**NubSure** is the Core Insurance Application (General Business) by Nubeero — a multi-tenant SaaS platform for end-to-end general insurance operations. Nigeria-first, NAICOM / NIID / NDPR compliant. One codebase, one deployment, every insurance company tenant runs in isolation.

These docs cover both the **internal architecture** (for the engineering team building NubSure) and the **partner API** (for Insurtechs integrating with NubSure-powered insurers).
